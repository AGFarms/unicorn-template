# Contributing

Thanks for your interest in `unicorn-template`.

## Ground rules

- Use **pnpm** (not npm/yarn).
- Node 20+.
- TypeScript strict — no `any` without a comment justification.
- Conventional commits (`feat:`, `fix:`, `chore:`, `docs:` ...).
- Run `pnpm lint && pnpm typecheck && pnpm test && pnpm build` before opening a PR.

## Scope

This is a **template**. Application logic, brand-specific copy, and
proprietary assets do not belong here. If you want a Kala-, DerbyFish-, or
portfolio-specific feature, fork the template and add it downstream.

## Reporting issues

Open a GitHub issue with a minimal repro.
